
# 🎓 Student Record System

A simple **Student Record Management System** built using **Java (Maven)** with **JDBC MySQL connectivity**.  
This project allows users to perform basic CRUD operations on student data such as adding, viewing, updating, and deleting records.

---

## 🚀 Features

- ➕ Add new student records
- 📄 View all students
- ✏️ Update student details
- ❌ Delete student records
- 🔍 Search student by ID
- Database connectivity using JDBC

---

## 🛠️ Tech Stack

- Java
- Maven
- JDBC
- MySQL
- IntelliJ / NetBeans (any IDE)

---

## 🗄️ Database

- MySQL database used to store student information
- Tables include:
  - Student ID
  - Name
  - Age
  - Course
  - Email (optional)
